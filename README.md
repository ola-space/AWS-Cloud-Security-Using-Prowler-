# AWS Cloud Security Assessment Using Prowler


---


## Overview


---

This project demonstrates a cloud security assessment of an AWS environment using Prowler.   
The assessment was performed to identify security misconfigurations, monitoring gaps, and identity management weaknesses across cloud services in Amazon Web Services.   
A detailed report containing the full analysis, findings, and remediation recommendations is included in this repository.


---

## Tools Used
- Prowler
- AWS CLI
- Kali Linux

---

## Scan Summary
The security scan performed 142 security checks across the AWS environment.

Result	Count
- Passed	64
- Failed	78
- Failure rate: 52.35%

The majority of failed checks were associated with:

- AWS Identity and Access Management
- Amazon CloudWatch
- Amazon VPC

This indicates that identity security, monitoring configurations, and network controls require improvement.


---

## Methodology

- Created an IAM audit user for security scanning.
- Configured AWS CLI credentials on Kali Linux.
  
Executed the security scan using:

prowler aws --profile blu_prowler_user --region us-east-1

Analyzed both the scan summary output and the detailed report generated by Prowler.
